# 实验三：软件实现与构建

要求原件见 `实验三_软件实现与构建.pdf`。截止 2026-11-29 23:59，提交到 cslab-cms。

## 实现概况

按实验二的 UML 类图与 M1–M10 模块划分，用 Python 3.12 + SQLite + Tkinter 实现酒店预订管理系统。

- 生产代码 6717 行（`code/src`，不含空行与注释），测试 1702 行
- 24 个类各对应一张 SQLite 表；`src/hotel/m01_account` … `m10_notify` 与模块编号一一对应
- 状态机、库存扣减、并发抢房、改价互斥、权限范围都有对应测试
- 登录页先选身份（顾客 / 前台 / 店长 / 片区负责人），选中后自动带出该身份的演示账号
- 顾客侧按订房流程组织：找酒店（城市 + 日期搜索、热门推荐卡片）→ 搜索结果（按门店分组，
  显示房型、床型、剩余间数与价格）→ 房型详情 → 下单确认 → 收银台 → 我的订单（卡片列表）
- 界面 20 屏（另含登录页），与实验二设计的界面清单一一对应：
  顾客侧找酒店、查询结果、房型详情、下单确认、支付、我的订单、提交评价；
  前台侧房态看板、办理入住、办理退房、客房打扫、前台开单；
  店长侧改价与审批、审批中心、本店员工；
  片区侧片区概览、价格区间、店长名册；
  以及按角色复用的消息中心与操作日志。
- 界面采用与实验二桌面端一致的产品化布局：左侧导航 + 顶部标题栏 + KPI 卡片 + 内容卡片，
  配色、字号、状态色统一在 `src/hotel/ui/theme.py`
- 操作过程截图见 `_过程材料/界面截图/`（31 张，按真实使用顺序生成，含异常与待办状态）

## 运行

```bash
cd code
python -m venv .venv
.venv/Scripts/python -m pip install -e ".[dev]"
.venv/Scripts/python -m hotel.seed        # 重建数据库并写入演示数据
.venv/Scripts/python -m hotel.ui.app      # 启动界面
```
